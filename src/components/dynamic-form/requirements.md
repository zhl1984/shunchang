# DynamicFormPanel 组件需求

## 功能目标

提供不依赖具体工作台的动态表单渲染组件，接收宿主传入的 schema、values、只读状态和主题，完成控件展示、简单联动、字段变化和局部校验。

## 使用场景

- 管理端内嵌路由通过 iframe 展示动态表单。
- 管理端其他页面未来直接复用表单渲染能力。

## 字段与展示内容

支持 `RADIO`、`MULTI_SELECTION`、`DROPDOWN`、`TEXT`、`NUMBER`、`DATE` 和 `BOOLEAN`；字段标签、单位、说明、必填标记、只读状态、选项及范围规则沿用 `src/dynamic-form/types.ts`。

## 交互规则

- 字段变化只更新组件内部快照并通过 `change` 事件通知宿主。
- `parent` / `parentValue` 字段按父字段当前值控制可见性。
- 字段级校验由 iframe 宿主通过协议请求执行，并通过 `validation` 事件返回结果；表单内部不展示独立校验按钮或校验状态操作区。
- 日期浮层打开或关闭后通过 `resize` 事件通知宿主重新计算 iframe 高度。
- 主题只使用 `theme` 属性，缺省固定为 `dark`，不读取管理端 theme store。

## 状态处理

- schema 为空时展示等待宿主数据的空状态。
- 宿主 schema、values 或只读状态变化时整体替换组件快照并清理旧校验结果。
- 不修改 props，也不持有业务对象或保存状态。

## 接口依赖

组件不直接请求接口，业务数据由 iframe 路由适配层或页面宿主传入。

## 验收标准

- 所有字段类型均可按 schema 正确渲染和编辑。
- `0`、`false`、空数组等有效值可以正常回显。
- 校验错误按字段展示，变化和尺寸事件参数类型明确。
- 深色/浅色由显式属性控制，默认深色。
