# 场景配置页需求

## 功能目标

展示场景列表，并提供场景相关扩展页面入口。

## 展示与交互约定

- 列表统一使用 `DmAppTable`，场景列表标题、搜索框、新增按钮及扩展入口按钮均放置在表格标题工具区。
- 场景名称仅展示名称，不再在名称下方显示场景说明。
- 扩展入口使用路由菜单配置中的 `icon` 渲染为图标按钮，并通过 Tooltip 展示对应标题，同时提供可访问名称。
- 当扩展入口中存在 `permissionKey === "development-config"` 的按钮时，该按钮显示在扩展按钮列表首位，其余按钮保持原有顺序。
- 页面不再展示独立的顶部概览卡片。

## 交互规则

- 点击 `scp-header-actions` 中的扩展按钮后先完成路由跳转。
- 跳转完成后通过主布局注入的面包屑 setter，将目标页面追加到当前面包屑列表。
- 重复点击同一路径时不得重复追加相同面包屑。

## 验收标准

- 扩展页面跳转成功后，面包屑保留场景配置入口并显示目标页面。
- 路由切换过程中的主布局默认面包屑不会覆盖追加结果。
