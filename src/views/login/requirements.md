# 登录模块需求

## 功能目标

为顺昌高质量数据生产平台提供统一登录入口。用户完成身份验证后保存登录凭证和用户资料，并进入原计划访问的业务页面。

## 页面布局

- 登录页使用全屏布局，不显示管理平台头部和左侧菜单。
- 页面左上角使用 `src/assets/images/logo.png` 作为品牌标识，并显示“顺昌高质量数据生产平台”。
- 登录面板在页面中水平、垂直居中；版权信息在页面底部居中显示，不放入登录面板。
- 登录面板展示平台名称及其下方副标题；账号字段仅支持账号输入。
- 平台名称下方的副标题增加四周 8px 内边距，字重为 400。
- 小屏设备保持登录面板居中并适配可用宽度。
- 页面跟随全局 theme store 适配浅色和深色主题。

## 表单字段

- 账号或邮箱：必填，初始为空，提交前去除首尾空格，最大长度为 100。
- 密码：必填，初始为空，最大长度为 32。
- 页面不预填或展示演示账号、演示密码，用户必须自行输入登录凭证。

## 登录流程

1. 用户填写账号和密码并提交表单。
2. 调用 `loginApi` 完成服务端 Cookie 会话建立，并获取可选用户信息。
3. 将用户信息交由 user store 保存在内存中，不持久化到浏览器存储。
4. 登录接口未返回用户信息时，调用 `getMemberInfoApi` 补充当前用户资料。
5. 登录成功后优先进入合法的站内 `redirect` 地址，否则进入首页 `/`。
6. 登录失败时清理无效会话并展示错误信息。

## 路由与访问控制

- 登录页面路由为 `/login` 和通用管理端入口 `/admin/login`，均使用 `fullscreen` 布局。
- 登录页根据当前路由判断是否为管理端入口：从 `/admin/login` 进入时副标题显示国际化文案“管理中台”并使用 `--dm-text` 颜色；其他入口显示默认副标题。
- 未登录用户访问需要认证的业务路由时跳转至 `/login`，并保留原目标地址。
- 已登录用户访问 `/login` 时直接进入首页。
- 业务路由权限递归读取用户 `menuTree` 各层级的 `permissionKey`，不能仅识别根节点。
- 注册当前用户业务路由前移除上一用户无权访问的动态路由；退出登录时清空全部动态业务路由，防止切换角色后菜单残留。

## API 与状态

- `loginApi`：提交账号和密码，返回 `LoginResult`。
- `getMemberInfoApi`：获取当前登录用户资料，返回 `MemberInfo`。
- `logoutApi`：退出当前登录会话。
- HttpOnly Cookie 由服务端负责保存和清理 Token；用户资料和登录状态由 `useUserStore` 保存在内存中。
- API 模块返回解包后的业务数据，页面不直接处理 AxiosResponse。

## 异常状态

- 必填字段为空时不发送请求，并提示用户补充账号和密码。
- 提交期间按钮显示加载状态，避免重复提交。
- 登录失败、用户信息获取失败时清理内存会话；初始化用户信息时的未登录 401 不显示全局错误弹框。
- 非法或外部跳转地址不得作为登录成功后的目标地址。

## 验收标准

- `/login` 能正常显示且不包含主布局。
- 登录页不预填凭证，不展示演示信息、平台能力或指标描述。
- 登录页用户可见文案统一来自简体中文语言包。
- 表单校验、登录请求、错误提示和加载状态正确。
- 刷新页面后通过 Cookie 重新请求用户资料，user store 不从 localStorage 恢复 Token 或用户信息。
- 未登录访问业务路由时正确跳转登录页并保留目标地址。
- 简体中文、浅色和深色主题下结构可正常展示。
- 页面通过格式化、ESLint、TypeScript 检查和生产构建。
