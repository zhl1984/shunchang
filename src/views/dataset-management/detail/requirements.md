# 数据集详情页需求

## 功能目标

展示单个数据集的基本信息，并把该数据集下的全部样本以缩略图卡片平铺展示。基本信息复用全局数据集 Store，样本列表通过后端分页接口按需加载。

## 使用场景

- 用户在数据集管理列表页点击某一行「查看」，进入 `/dataset-management/{id}`。
- 用户直接访问详情地址（深链接）查看数据集基本信息与样本。
- 用户向下滚动样本图库，按需连续浏览全部样本。

## 字段与展示内容

标题区域：

- 数据集名称：`Dataset.name`，作为页面标题展示。
- 状态：`Dataset.status`，以标题旁的标签展示，支持 `SUCCESS`、`FAILED` 和空值。

基本信息字段（每行 2 个，标题区域已有的数据集名称和状态不重复展示）：

- 数据集类型：`Dataset.dataType`。
- 数据集说明：`Dataset.description`，为空时显示 `--`。
- 项目引用：`Dataset.projectReferenceCount`。
- 数据单元数：`Dataset.itemCount`。
- 创建时间 / 更新时间：`Dataset.createdAt` / `Dataset.updatedAt`，使用统一日期时间格式化，精确展示到时、分、秒。

样本卡片（桌面端按 4～6 列均衡排布）：

- 缩略图：`DatasetSample.imagePath`，为空或加载失败时展示占位块。
- 内容区：仅展示按分页推导的样本编号，文案为「样本 {no}」，不展示样本名称等其他信息。
- 样本编号按当前累计列表中的顺序从 1 连续递增。

## 交互规则

- 基本信息来自全局数据集 Store，不额外请求数据集详情接口。
- 基本信息区参考质检详情采用 `1:2` 两列布局，右侧字段组从卡片宽度约三分之一处开始。
- 样本列表通过 `GET /datasets/samples/pageList` 按页请求，首次及后续每次加载 10 条；页面累计追加接口结果，不做前端切片。
- 页面不展示分页组件；列表底部进入视口且仍有未加载样本时，自动请求下一页，直至已加载数量达到接口总数。
- 缩略图区域固定 16:9，图片使用 `object-fit: contain` 居中展示，比例不匹配时四周留浅灰底色，不裁切图片。
- 桌面端在 4～6 列之间选择末行空位最少的列数，避免少量数据出现明显不均衡的尾行；6 条保持单行、7 条按 4+3、8 条按 4+4 展示。
- 缩略图区域宽度不足时按列数降级：视口变窄依次限制为 4、3、2 列。
- 鼠标悬停在卡片上时展示蓝色底块，文字反白；蓝色底块比卡片左右各宽出 6px，因此网格间距不得小于该出血量的两倍。
- 缩略图顶部保留 6px 间距，使悬停时图片上方可见少量蓝色底色。
- 点击有有效图片的卡片后使用公共图片预览组件打开大尺寸居中预览；弹窗宽度约占视口的 68%，最大 1200px，并受当前视口宽高限制。
- 图片预览保持原图比例完整展示，不裁切；弹窗标题统一为「查看图片」，不展示样本编号等业务文字。图片顶部为标题和关闭按钮预留独立空间，不得与按钮重叠；点击关闭按钮或遮罩后退出预览。
- 图片预览使用半透明深色遮罩；图片底部中央悬浮展示缩小、放大和适应窗口三个图标按钮，缩放范围限制在 50% 至 300%，适应窗口将缩放比例恢复为 100%。
- 图片显示区域在弹窗打开后保持固定高度，放大、缩小和恢复操作均不得改变弹窗整体高度。
- 卡片使用原生按钮元素，键盘可聚焦，聚焦态与悬停态表现一致。
- 样本列表为空时展示空状态，文案统一为「暂无数据」；无样本时不展示分页。

## 状态处理

- 数据集 ID 非法（非正整数）：展示加载失败结果页，不发起任何请求。
- 基本信息加载失败，或数据集不在 Store 集合中（例如状态非 `SUCCESS`，列表接口会过滤掉）：基本信息展示 `--` 占位，样本图库照常加载，不视为整体失败。
- 样本加载中：图库区域展示 loading。
- 后续页加载中：保留已展示的样本，并在列表底部展示 loading，避免图库整体闪烁。
- 样本加载失败：图库区域展示 Ant Design Empty，文案统一为「暂无数据」，不展示重新加载按钮。
- 后续页加载失败：保留已成功加载的样本，并停止本轮自动加载，避免重复触发失败请求。
- 样本接口返回 HTTP 404 时，保留详情地址与基本信息，在图库区域展示「暂无数据」；接口资源不存在不得触发全局 `/404` 跳转。
- 样本为空：图库区域展示 Ant Design Empty，文案统一为「暂无数据」。
- 缩略图加载失败：该卡片缩略图区域展示占位块，不展示浏览器破图。
- 数据集切换或请求重叠时丢弃过期响应，避免旧请求结果覆盖新数据。

## 接口依赖

- `GET /datasets/samples/pageList`：按 `datasetId`、`pageNo`、`pageSize` 分页查询样本，返回 `list[{ itemId, imagePath, name }]`、`total`、`pageNo`、`pageSize`。
- `GET /datasets`：由数据集 Store 提供，详情页复用其集合获取基本信息。
- API 层将 `itemId` 映射为页面模型的 `id`，`imagePath` 与 `name` 的 null 值原样保留。

## 验收标准

- 列表页「查看」按钮跳转到对应数据集的详情地址。
- 样本接口返回 HTTP 404 后仍停留详情页，图库显示「暂无数据」且不展示重新加载按钮。
- 标题区域展示数据集名称和状态标签，基本信息区不重复展示这两个字段。
- 基本信息每行 2 个字段，空值统一展示 `--`。
- 基本信息区右侧字段组从卡片约三分之一处开始，与质检详情的信息布局一致。
- 创建时间和更新时间展示完整日期及具体时、分、秒。
- 样本图库桌面端按 4～6 列均衡排布，6 条单行、7 条按 4+3、8 条按 4+4 展示，窄屏按 4 / 3 / 2 列降级。
- 缩略图区域为 16:9，图片居中不裁切。
- 悬停时蓝色底块明显宽于卡片，文字反白。
- 缩略图顶部具有少量间距，悬停时能够露出蓝色背景。
- 卡片内容区只显示样本编号，不显示样本名称等其他信息。
- 点击有效图片卡片后打开约占视口 68% 的大尺寸图片预览，标题显示「查看图片」，关闭按钮不遮挡图片且不发生页面跳转。
- 预览遮罩具有透明度，图片底部中央的三个悬浮按钮可分别缩小、放大和恢复适应窗口状态。
- 图片缩放过程中弹窗与图片区高度保持稳定；预览能力来自 `src/components/ImagePreview` 公共组件。
- 滚动至列表底部时携带递增页码请求下一页，并将结果追加到现有列表；样本编号连续。
- 样本接口固定按 10 条/页请求，页面不展示总数、页码与前后翻页按钮；全部加载后不再请求。
- 非法 ID 不触发接口请求并展示失败页。
- 用户可见文案均由国际化语言包提供。
- 格式检查、ESLint、类型检查、相关测试和生产构建通过。

## 待确认假设

- 样本编号采用分页推导的全局序号；若后端返回顺序变化，编号会随之变化。后端补充稳定的样本顺序字段后可替换该规则。
- `imagePath` 按「绝对地址与协议相对地址原样使用，其余前缀 `VITE_API_BASE_URL`」解析；若实际为对象存储 key 且需要独立域名，只需调整 `resolveSampleImageUrl`。
- 卡片内容区文本左对齐。
