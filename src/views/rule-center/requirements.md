# 规则中心页面需求

## 功能目标

提供规则列表浏览、搜索、查看、编辑、删除和新建入口。规则字段、条件结构和接口行为以规则中心 API 契约为准，页面负责展示、交互编排和状态反馈。

## 使用场景

- 用户访问 `/rule-center` 查看规则列表。
- 用户通过关键词筛选规则、标签名称或属性内容。
- 用户从标题工具区新建规则，或从列表操作列查看、编辑和删除规则。

## 页面展示

- 使用全局 `DmAppTable`，标题区展示“规则中心”。
- 标题工具区右侧提供搜索框和“新建规则”按钮。
- `titleTool` 工具区内的按钮及输入、选择等交互控件统一使用 `size="large"`，保持头部控件高度一致。
- 列表展示规则名称、标签名称、条件约束摘要和操作列。
- 操作列固定在右侧并设置明确宽度，使用 `table-actions-cell` 和 `table-actions` 全局样式。
- 分页由表格组件统一管理，默认支持每页 10、20、50 条切换。

## 操作列规范

- 查看、编辑、删除均使用 Ant Design Vue `a-button` 的 `type="link"` 文字链接按钮。
- 操作列不使用查看、编辑、删除图标，直接展示国际化文字文案。
- 操作按钮使用正常字号，按钮横向排列并保持 8px 间距。
- 删除按钮保留 `danger` 状态，明确表达高风险操作。
- 操作文案统一从国际化语言包读取，不在模板中硬编码。

## 交互规则

- 搜索输入支持清空，关键词变化后更新列表筛选结果。
- 点击新建打开规则弹窗。
- 点击查看或编辑前请求规则详情；查看模式只读，编辑模式允许修改并保存。
- 删除前展示二次确认弹窗，确认后调用删除接口并刷新列表；取消或失败时保留当前数据。
- 条件面板支持 WHILE/THEN 结构以及 AND、OR 逻辑；切换标签时重置条件和约束，切换属性或操作符时清空对应值。
- 标签树支持递归展示，只有叶子标签可选；打开时展开当前标签路径的父级节点。

## 状态处理

- 列表加载中展示加载状态，加载失败按统一错误反馈处理。
- 列表为空时使用表格统一空状态。
- 详情加载期间禁止重复打开或提交当前规则。
- 保存、删除请求期间禁用对应操作，成功后刷新规则集合。
- Store 初始化以较大 pageSize 获取完整规则集合，页面负责关键词过滤，表格组件负责分页。

## 数据与接口依赖

- 规则列表、详情、新建、更新和删除请求统一通过 `src/api/rule.ts` 暴露。
- 页面通过规则 Store 获取和刷新规则列表，不直接使用 Axios。
- 条件摘要优先展示后端返回的 `conditionSummary`，前端不重复拼接摘要。
- UI 表单模型与接口请求模型分离，提交前完成字段转换和校验。

## 验收标准

- 访问 `/rule-center` 可正常进入规则中心。
- 搜索框、新建、查看、编辑和删除入口均可按当前接口状态正确响应。
- 操作列只显示正常字号的文字链接按钮，不显示操作图标；删除链接具有危险态。
- 操作列保持横向排列、8px 间距且不换行，固定列不会挤压内容列。
- 标题工具区内按钮和控件均以 `large` 尺寸展示，视觉高度保持一致。
- 规则弹窗内容超出可用高度时仅主体滚动，标题和底部操作区保持可见。
- 浅色和深色主题下文字链接、危险态和表格布局均可辨识。
