# 开发配置页面需求

## 功能目标

展示开发配置页面的定位说明和平台预置的标注设计器，为后续维护标注类型提供统一入口。

## 使用场景

- 配置人员进入开发配置页面时，快速了解页面用途和可维护范围。
- 配置人员后续在页面中查看平台预置的标注设计器并维护标注类型。

## 字段与展示内容

- 页面不展示额外的配置中心头部卡片，直接进入标注设计器和标注类型列表。
- 页面标题展示“开发配置”。
- 页面说明展示设计器的来源、可维护内容和不可修改限制。
- 标注设计器区域展示“只读”状态以及 CT、3D 点云两类平台预置设计器。
- 每个设计器展示名称、用途说明、支持工具、输入格式和交付格式。
- 标注类型表格展示名称、说明、数据类型、标注设计器和操作入口。
- 标注类型表格标题显示为“标注类型列表”。
- 标注类型表格操作栏使用“编辑”“删除”文字按钮。
- 原型列表展示肺部、自动驾驶 3D 点云、腹部、盆腔和头颈部五种标注类型。

## 交互规则

- 标注设计器仅用于查看，不提供新增、编辑和删除操作。
- 点击“新建标注类型”打开独立弹窗，弹窗字段包括标注类型名称、标注设计器、数据类型和类型描述。
- 标注类型名称、标注设计器和数据类型必填，类型描述选填。
- 数据类型依赖标注设计器；未选择设计器时保持禁用，切换设计器时清空原数据类型。
- CT 设计器可选择 DICOM，3D 点云融合标注设计器可选择 nuScenes、KITTI 或 Waymo TFRecord。
- 保存时先执行前端表单校验，调用标注类型创建或更新接口；接口成功后关闭弹窗并刷新列表。
- 新建、编辑或删除接口返回 HTTP 400 时，页面展示接口返回的 `message` 或 `msg`，并保持当前表单或列表状态。
- 表格顶部不展示模块标题和说明，改为搜索框与新建按钮组成的工具栏。
- 搜索框支持按标注类型名称、说明、数据类型或标注设计器实时筛选，并在搜索后回到第一页。
- 已被场景使用的标注类型不可编辑，编辑按钮显示为禁用状态；删除操作必须经过二次确认。
- 删除确认使用 Ant Design 的确认弹窗，显示当前标注类型名称，确认后从当前列表移除。
- 编辑和删除操作使用纯图标按钮，并通过无障碍名称说明用途。
- 列表底部展示当前范围、总条数、页码和每页条数选择器。

## 状态处理

- 页面内容区适配浅色主题、深色主题和常见内容宽度。
- 说明文字在窄屏下自然换行，不出现横向溢出。
- 两个设计器在桌面端并排展示，在窄屏下切换为单列。
- 标注类型列表在内容宽度不足时允许横向滚动，避免字段相互遮挡。

## 接口依赖

- `src/api/development-config.ts` 根据开发配置 OpenAPI 统一维护接口和数据类型；设计器和标注类型页面均使用接口数据。
- 标注设计器支持按状态查询列表以及按 ID 查询详情，响应包含工具、输入格式和输出格式。
- 标注类型支持创建、更新、删除和分页查询，提交的数据格式必须属于所选设计器的输入格式。
- 页面和组件仅调用 API 模块暴露的业务函数，不直接使用 Axios 或 HTTP 实例。

## 验收标准

- 页面内容区的留白、字体层级和背景样式与成员管理、模型配置页面保持一致。
- 页面展示的所属模块、标题和说明与原型一致。
- 标注设计器作为独立组件放在页面 `components/` 目录并由入口页面引入。
- 设计器卡片的内容、标签层级和两列布局与原型一致。
- 标注类型列表作为独立组件放在页面 `components/` 目录并由入口页面引入。
- 标注类型的搜索工具栏、表头、列表字段、图标操作和分页布局与原型一致。
- 新建标注类型弹窗作为独立组件放在页面 `components/` 目录并由入口页面引入。
- 弹窗标题说明、字段顺序、设计器与数据类型联动、取消和保存操作与原型一致。
- 新建和编辑弹窗的标题图标在图标底色容器内保持水平、垂直居中。
- 删除标注类型使用 Ant Design 确认弹窗，不额外创建删除弹窗组件。
- 用户可见文案由国际化语言包统一管理。
