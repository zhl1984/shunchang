# 项目管理

## 功能目标

展示项目状态统计和项目列表，支持按名称搜索、后端分页，以及新建和查看项目。

## 字段与交互

列表展示项目名称、项目状态、SALT 自主学习状态、项目人数、样本数量、截止时间和查看/删除操作。项目人数和样本数量列的标题左对齐，数字内容右对齐。项目状态列支持按“系统处理中、进行中、已完成、异常”筛选；SALT 自主学习状态列支持按“已开启、未开启”筛选，筛选条件提交后由服务端查询并回到第一页。截止时间列支持表头排序，升序通过 `sortField=deadline&ascSort=true` 请求服务端，降序通过 `sortField=deadline&ascSort=false` 请求服务端，恢复默认顺序时不传排序参数；切换排序后回到第一页。新建按钮打开新建标注项目弹窗，查看操作跳转到对应项目详情页。

顶部状态统计卡片不显示边框；数字使用与列表样本数量一致的默认界面字体和数字样式，不单独引入展示字体。
统计卡片内的标签和数字整体垂直居中，四个页面保持一致。
统计卡片文字左侧展示与卡片含义匹配的蓝色图标，图标置于浅蓝色圆形底中。

从项目列表查看项目时，使用项目编码进入 `/project-management/:id` 详情路由，并通过主布局面包屑 setter 在“项目管理”后追加“项目详情”路径。

删除项目时先弹出确认框；确认后调用删除接口，成功则刷新列表和统计卡片并提示成功，失败则提示错误。

新建与查看复用四步弹窗，步骤依次为基础信息、标注场景、团队成员和数据来源。第一阶段先实现弹窗、步骤条、切换编排与四个步骤组件的统一接口，不接入各步骤的具体业务字段与选项接口。

新建模式只能通过上一步、下一步按顺序切换。下一步必须先调用当前步骤的 `validate()`，校验成功后调用 `getForm()` 采集当前步骤快照；第四步完成校验和采集后汇总创建参数。查看模式不执行表单校验，允许点击步骤条直接切换。

四个步骤组件使用动态组件与 `KeepAlive` 保持切换前的内部状态。关闭弹窗后销毁本次会话缓存，再次打开新建弹窗必须恢复初始状态；查看其他项目时必须重新加载对应详情。

每个步骤组件只维护自己的表单模型，并统一向外暴露 `validate(): Promise<void>` 和 `getForm()`。外层按步骤保存表单快照，查看详情时将后端详情对象转换为四段前端表单数据，创建时再将四段数据汇总并转换为后端创建参数。

标注场景步骤包含必填的标注类型和标注场景。标注类型只展示启用项；场景根据已选标注类型筛选，未选择标注类型时禁用。切换标注类型时清空已选场景，避免提交不匹配的组合。

所有步骤组件同时接收完整 `draft` 作为只读业务上下文，但只维护和输出本步骤的 `modelValue`。团队成员步骤根据 `draft.scene.sceneId` 获取场景绑定的质量方案，按质量方案详情的层级顺序生成质检人员选择；标注员选择树使用成员 Store 的 `annotatorTree`，质检员选择树使用 `qualityTree`；标注人员至少选择一名，每个质检层级也至少选择一名。

数据来源步骤只允许选择导入成功的数据集，数据类型随数据集自动带出。每批样本数必须为正整数；开启 SALT 自主学习后，达标准确度必须为 1～100 的整数，轮数上限必须为正整数。

页面标题、统计卡片、表格列名、状态标签、操作按钮、搜索占位文案和错误提示统一通过 `projectManagement` 国际化语言包维护，页面与 API 层不硬编码用户可见中文文案。

## 接口依赖

列表使用 `GET /projects`、`GET /projects/statistics`，通过 `pageNo/pageSize/keyword/status/iterationEnabled/sortField/ascSort` 查询；`sortField` 当前仅使用 `deadline`。

新建与查看后续使用 `POST /projects`、`GET /projects/{projectCode}`。当前详情协议未包含标注员和质检员，团队成员详情字段与相关选项接口在第二阶段开发对应模块前确认。

## 验收标准

### 截止日期规则

新建项目第一步的截止日期仅允许选择今天及之后的日期，日期选择器应禁用今天之前的日期；查看项目时保留并展示后端返回的原始截止日期。

页面路径为 `/project-management`，统计卡片与表格可加载，搜索、状态筛选、截止时间排序和分页可交互，搜索、状态筛选和分页触发后端请求，加载失败与空数据有明确状态。

- 状态筛选使用项目列表接口的 `status` 和 `iterationEnabled` 查询参数；清空筛选时不传对应参数。
- 截止时间排序由项目列表接口对完整结果集执行，不允许仅对当前页数据做前端排序。

第一阶段验收标准：

- 新建和查看均显示四步步骤条及对应步骤组件。
- 新建模式不能点击步骤条跳步，当前步骤校验成功后才能进入下一步。
- 查看模式可以点击任意步骤，且不会触发表单校验。
- 步骤切换保留组件内部状态，关闭弹窗重新打开后不保留旧会话状态。
- 外层能够逐步收集四段表单快照，并预留详情拆分与创建汇总转换入口。
- 第一阶段不发送创建请求，不使用硬编码模拟业务数据填充步骤组件。
