# 模型配置页面需求

## 弹窗视觉与交互

- 接入模型和编辑模型使用统一的弹窗结构：图标标题区、说明文字、可滚动表单主体和底部操作区。
- 接入模型中模型名称、协议类型、用途、API 地址、API 密钥、自迭代配置和模型输出标签按截图布局展示。
- 编辑模型中名称、协议类型、API 地址及已有输出标签只读；用途、API 密钥和自迭代配置可修改。
- 表单主体超出视口时仅主体区域滚动，底部取消和提交按钮保持可见。

## 模型列表查询与排序

- 模型列表标题工具区提供模型名称搜索框，输入关键词后按 Enter 查询，清空输入框时恢复全部模型；搜索通过分页接口的 `keyword` 参数提交并回到第一页。
- 自迭代状态以胶囊标签展示：已开启使用绿色状态样式，未开启使用橙色状态样式；不支持自迭代的模型在列表中按未开启展示。
- 自迭代状态列支持按“已开启”和“未开启”单选过滤，筛选值按接口约定通过分页接口的 `selfIterationSupported` 布尔参数提交。
- 切换自迭代状态过滤条件时回到第一页，并携带当前页大小重新请求模型列表；清空过滤条件时不传该参数。
- 接入时间列展示模型创建时间，并支持服务端升序和降序排列；升序发送 `sortField=createdAt&ascSort=true`，降序发送 `sortField=createdAt&ascSort=false`，恢复默认顺序时不传排序参数。
- 切换接入时间排序后回到第一页，翻页时继续携带当前排序条件。

## 接口依赖与验收标准

- 模型列表使用 `GET /models/page`，请求参数包含 `pageNo`、`pageSize`，以及可选的 `keyword`、`selfIterationSupported`、`sortField` 和 `ascSort`。
- 选择任一自迭代支持状态后，请求参数与界面选择一致，列表和分页总数使用接口响应更新。
- 点击接入时间表头可在升序、降序和默认顺序之间切换，排序由接口作用于完整结果集，翻页及修改每页条数仍能正常加载。
