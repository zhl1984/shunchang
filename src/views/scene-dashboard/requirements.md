# 场景看板需求

## 功能目标

为用户提供场景与专业能力的统一浏览入口。页面暂使用前端维护的临时内容，不接入后端接口。

## 使用场景

用户从配置中心进入场景看板，浏览主推产品、正在接入的场景和专业能力，并通过轮播、横向滚动或搜索查看内容。

## 展示内容

- 顶部展示主推产品轮播，包括图片、分类、标题、简介和进入场景操作。
- 主推产品 Banner 的文字块距左侧固定 120px，标题、简介和按钮统一左对齐；分类与主标题间距为 24px，主标题与简介间距为 16px，简介与进入场景按钮间距为 40px，简介行高为 1.5。
- 主推产品点击【进入场景】后跳转到场景配置页面；未开放场景继续保留提示反馈。
- 中部展示正在接入的场景卡片，包括图片、分类、标题、简介和未开放状态。
- 底部展示专业能力卡片，包括图标、标题、简介和能力入口。

## 交互规则

- 主推产品使用 Ant Design Vue 轮播，自动播放；鼠标悬停或键盘聚焦时暂停，离开后恢复。
- 场景卡片支持左右按钮、鼠标拖拽以及 Enter/Space 键盘操作。
- 未开放场景不可进入，触发国际化提示。
- 专业能力支持按标题和简介搜索，无匹配时显示空状态。
- 页面卸载时清理轮播定时器。

## 状态处理

- 临时场景状态为 `available` 或 `coming-soon`。
- 搜索无结果显示空状态。
- 当前页面不包含接口加载和接口失败状态；接入 API 后需补充。

## 路由与权限

地址为 `/scene-dashboard`，使用主布局并归属于配置中心。当前阶段由前端显式放行，后续由后端菜单权限控制。

## 验收标准

- 页面通过主布局渲染，菜单标题为“场景看板”，图标为 `AppstoreAddOutlined`。
- 三个展示模块职责独立，文案均来自国际化语言包。
- 轮播暂停、恢复和销毁行为可验证。
- 卡片操作具备 Tooltip、`aria-label` 和键盘支持。
