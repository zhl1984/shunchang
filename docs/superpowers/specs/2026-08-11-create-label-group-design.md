# 新增标签组设计

## 目标

在标签树面板头部启用“分组”按钮，并提供新增标签组弹窗。弹窗支持名称、描述和级联父标签组选择；创建成功后刷新标签树并选中新分组。

## 数据模型

`LabelTreeNode` 调整为以 `type` 区分的联合类型。分组节点包含 `pid`、`id`、`type: "group"`、`name` 和 `description`，不包含 `code`；标签节点继续要求 `code`，并保留 `color`、`tools` 和 `props`。

## 树选择规则

分组和标签都允许选中。标签选中时对外触发 `select(labelId)`；分组选中时对外触发 `select(null)`，因为右侧面板只展示标签信息。树内部始终保留真实的 `selectedKeys`，用于计算新增分组的默认父级。

## 弹窗

新增 `CreateLabelGroupModal.vue`。弹窗包含必填名称、选填描述和必填父标签组。父标签组使用级联选择器，只展示分组节点，并提供“无父标签组”根选项；该选项提交为 `pid: null`。

弹窗打开时根据当前选择计算默认父级：选中分组时使用该分组，选中标签时使用标签的直接父分组，没有有效选择时使用无父标签组。提交成功后关闭并重置表单，通知树面板刷新、展开父分组、选中新分组并触发 `select(null)`。

## 状态与反馈

提交期间禁用重复提交和关闭操作。表单校验错误由字段展示，API 错误使用全局消息提示；成功后显示成功消息。所有文案进入中文语言包，样式使用主题变量并沿用组件短前缀规则。

## 验收标准

- 分组节点可选中并触发 `select(null)`。
- “分组”按钮可以打开新增标签组弹窗。
- 父标签组级联选项只包含分组，并包含无父标签组选项。
- 默认父级符合当前树选择规则。
- 分组创建请求不包含 `code`。
- 创建成功后刷新、展开父级并选中新分组。
- 相关测试、类型检查、ESLint 和构建通过。
