# 场景看板设计

## 背景与目标

整理现有 `scene-dashboard` 页面，使其符合项目的 Vue、路由、国际化、主题、组件拆分和可访问性约定。页面暂不接入后端，临时展示内容继续保留，但统一由国际化语言包维护。

## 页面结构

页面使用现有 `main layout`，不再引入页面自有布局壳，包含三个模块：

1. 顶部主推产品轮播，使用 Ant Design Vue 轮播组件。
2. 中部正在接入的场景卡片横向区域。
3. 底部专业能力卡片网格和搜索。

页面入口 `index.vue` 仅负责模块编排。模块拆分为 `SceneHero.vue`、`SceneCardRail.vue` 和 `CapabilityGrid.vue`；轮播状态和定时器逻辑提取至 `useSceneCarousel.ts`。

## 数据与国际化

场景和能力数据使用稳定 key、图片和状态定义，标题、描述、按钮、Tooltip、`aria-label`、空状态及消息全部从 `zh-CN` 语言包读取。临时内容不接入 API，也不在组件模板中硬编码用户可见中文。

场景状态保留 `available` 与 `coming-soon`。未开放场景不可误认为已进入，点击时显示国际化提示。

## 路由

`/scene-dashboard` 使用 `main` 布局，放入配置中心菜单分组，路由图标使用 `AppstoreAddOutlined`，标题使用独立的 `navigation.menus.sceneDashboard` key。当前阶段由前端显式放行，不要求后端菜单树立即提供权限项；后续接入后端权限时再恢复权限约束。

## 交互与无障碍

- Hero 自动播放默认开启，鼠标悬停时暂停，离开后恢复。
- 组件卸载时清理所有轮播定时器。
- 轮播、横向滚动、搜索等操作使用 `handleXxx` 命名的具名处理函数。
- 图标按钮提供 Tooltip 和与国际化一致的 `aria-label`。
- 场景卡片支持键盘 Enter/Space 操作，并明确未开放状态。
- 模板中不直接调用 `message` 或书写复杂业务表达式。

## 样式

组件使用带短前缀的 scoped class。颜色、字号和主题相关值优先使用项目主题变量、字体工具类和间距工具类；保留已确认的大屏尺寸规则，清理重复覆盖样式，并兼容浅色、深色主题及内容溢出。

## 验收标准

- `yarn type-check`、`yarn lint`、`yarn format:check` 和 `yarn build` 通过（排除与本页面无关的既有问题需单独说明）。
- 场景看板可通过主布局访问，菜单显示在配置中心且文案、图标正确。
- 三个页面模块职责清晰，页面入口不再承载全部交互和样式。
- 所有用户可见文案和无障碍文案均来自国际化语言包。
- Hero 悬停暂停、离开恢复、卸载清理定时器均可验证。
