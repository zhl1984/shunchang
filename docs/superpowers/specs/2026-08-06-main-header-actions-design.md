# 主布局 Header 操作区设计

## 功能目标

移除 Header 现有的平台标题文字，改为靠右排列的操作区，依次展示浅色/深色主题切换按钮和可点击的用户信息下拉模块。

## 实现范围

- 直接修改现有的 `src/layouts/main/header.vue`，不拆分新的子组件。
- 复用现有 theme store、user store、退出登录 API、Vue Router、Ant Design Vue 组件和图标库。
- 仅补充本次 Header 操作所需的国际化文案。
- 实现前同步更新现有主布局需求文档。
- 不新增依赖、不修改路由定义、不创建 Git 提交。

## 布局与展示

Header 移除当前的平台标题，所有内容靠右排列，展示顺序如下：

1. 主题切换图标按钮。
2. 用户信息下拉触发区域。

主题按钮根据当前浅色或深色状态显示对应图标，并提供国际化的无障碍说明。用户信息区域左侧使用 Ant Design Vue 通用用户头像图标，右侧分为两行：右上展示用户名，右下展示角色名称。整个用户信息区域均可点击，并具有明确的鼠标指针和悬停反馈。

Header 继续继承主布局提供的 `--main-header-height` 和现有主题 CSS 变量。浅色、深色主题下均需正常显示；用户名和角色名称过长时不得破坏 Header 布局。

## 数据读取与展示规则

`header.vue` 读取以下状态：

- 从 `useThemeStore` 读取 `isDark`。
- 从 `useUserStore` 读取 `user`。

用户名优先展示 `userName`，为空时展示 `loginName`；角色展示 `roleName`。用户名或角色无法获取时，使用国际化兜底文案。

头像固定使用 Ant Design Vue 的通用用户图标。本次不增加头像地址、用户名首字、头像上传或个人资料编辑功能。

## 主题切换交互

Header 只提供浅色和深色两种直接切换状态：

- 当前实际主题为浅色时，点击按钮调用 `setThemeMode("dark")`。
- 当前实际主题为深色时，点击按钮调用 `setThemeMode("light")`。

theme store 现有的 `system` 模式继续保留，供后续其他设置入口使用。如果 Header 加载时存储模式为 `system`，则根据解析后的 `isDark` 判断当前实际主题，并在点击后切换为相反的显式浅色或深色模式。

## 用户下拉与退出登录

点击用户信息区域后打开 Ant Design Vue 下拉菜单。菜单当前只包含一个国际化操作项：退出登录。

退出流程如下：

1. 将退出状态设置为处理中，避免用户重复点击并发起重复请求。
2. 调用现有 `logoutApi()`，由服务端清理 HttpOnly Cookie。
3. 接口成功后调用 `userStore.clearSession()` 清理前端内存用户状态。
4. 使用路由替换方式跳转到 `/login`，避免通过浏览器后退直接回到已退出的业务页面。
5. 操作结束后恢复退出按钮状态。

如果退出接口失败，则保留当前用户状态并停留在当前页面。请求错误继续由现有 HTTP 层负责提示，Header 不重复展示错误消息。

## 组件职责边界

主题按钮和用户下拉均属于 Header 内部的小型操作，目前没有跨布局复用需求，因此统一保留在 `header.vue` 中，不新增 `UserDropdown` 或 `ThemeToggle` 子组件。

如果后续主题入口增加系统模式和更多设置，或用户菜单增加个人资料等独立功能，再为对应职责创建组件和独立需求文档。

## 验收标准

- Header 不再显示平台标题文字。
- 主题按钮只在显式浅色和深色模式之间切换。
- 通用头像、用户名和角色名称正常展示，长文本不会破坏 Header 布局。
- 点击用户信息区域可打开包含“退出登录”的下拉菜单。
- 退出操作能够阻止重复点击，依次完成接口调用、用户状态清理和 `/login` 跳转。
- 退出失败时保留当前用户和当前页面。
- 格式化、ESLint、TypeScript 类型检查、现有测试和生产构建全部通过。
