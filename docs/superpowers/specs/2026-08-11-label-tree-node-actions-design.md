# 标签树节点编辑与删除设计

## 目标

为标签管理页面的树节点增加悬浮操作区，使分组和标签都可以编辑或删除。编辑复用现有创建表单；删除根据节点类型和分组后代内容执行确认、阻止或级联删除。

## 节点操作区

- 鼠标悬浮到分组或标签整行时，在节点最右侧显示编辑和删除图标按钮。
- 非悬浮状态隐藏操作按钮，不占用名称和说明的主要展示空间。
- 操作按钮阻止点击事件冒泡，不触发树节点选择，也不改变分组展开状态。
- 编辑和删除按钮均提供明确的可访问名称及国际化文案。

## 通用节点弹窗

将现有组件重命名：

- `CreateLabelGroupModal.vue` 重命名为 `LabelGroupModal.vue`
- `CreateLabelModal.vue` 重命名为 `LabelModal.vue`

两个组件均支持：

- `mode: "create" | "edit"`
- 对应的显隐状态
- `nodeId: string | number | null`

创建模式保持现有行为，根据当前节点计算默认父标签组并调用创建 API。

编辑模式根据 `nodeId` 从 label store 的 `mapping` 中读取节点并回填表单：

- 分组：名称、父标签组、说明
- 标签：名称、所属标签组、编码、说明

编辑模式标题分别显示“编辑分组”和“编辑标签”，提交时调用 `updateLabelTreeNodeApi()`。节点类型不可修改。父标签组变更视为节点移动；界面不排除当前分组或后代分组，不校验循环关系，由后端负责最终保障。

编辑成功后弹窗刷新 label store 并通知树面板。树面板保留编辑节点的选中状态，并展开节点移动后的父级路径。

## 删除规则

### 标签

点击删除后打开确认框：

- 标题：删除标签
- 内容：确认删除 {labelName} 吗？
- 操作：取消、删除

确认后调用删除 API，刷新 label store。

### 空分组

没有任何子节点的分组打开确认框：

- 标题：删除分组
- 内容：确认删除 {groupName} 吗？
- 操作：取消、删除

确认后调用删除 API，刷新 label store。

### 包含标签的分组

只要分组的任意层级后代中存在标签：

- 不打开删除确认框
- 不调用删除 API
- 直接提示“{groupName} 分组下面有标签，不能删除！”

### 仅包含空分组后代的分组

如果分组存在后代，但整个后代树中都没有标签：

- 不打开删除确认框
- 直接调用删除 API
- 级联删除当前分组及其全部分组后代

API 删除行为同步调整为：

- 标签可以直接删除
- 空分组可以直接删除
- 仅包含分组的子树可以级联删除
- 分组子树存在标签时拒绝删除，作为界面检查之外的最终保障

## 删除后的树状态

- 删除完成后刷新 label store。
- 当前选中节点仍存在时保留选择。
- 当前选中节点被删除时清空树选择并对外触发 `select(null)`，不自动选择其他节点。
- 搜索状态下执行删除后，重新基于最新 store 数据计算当前搜索结果。

## 节点选择契约

- 分组和标签被选择时都对外触发 `select(node.id)`。
- 页面首次初始化完成后保持未选择状态，不自动选择首个标签，也不触发 `select`。
- 创建或编辑节点后选中保存的节点，并触发对应节点 ID。
- 树选择失效或被清空时触发 `select(null)`。

## 创建标签入口

- 没有选中树节点时，创建标签按钮禁用。
- 选中分组或标签时，创建标签按钮均可用。
- 选中分组时默认使用该分组；选中标签时默认使用标签的直接父分组。
- 选中标签没有父分组时默认“无父标签组”，提交参数使用 `pid: null`。
- 创建弹窗仍允许用户手动切换所属标签组。

## 国际化

新增或调整的用户可见文案全部维护在语言包中，包括：

- 编辑分组、编辑标签
- 删除分组、删除标签
- 删除确认内容
- 分组包含标签时的阻止提示
- 编辑、删除按钮的可访问名称

## 测试范围

- 分组和标签节点均渲染悬浮操作按钮。
- 编辑、删除按钮不会触发节点选择或分组展开。
- 两个弹窗在创建和编辑模式下显示正确标题。
- 编辑模式正确回填字段并调用更新 API。
- 编辑移动节点后刷新树、保留选择并展开新父级路径。
- 标签和空分组需要确认后才删除。
- 含任意后代标签的分组显示阻止提示且不调用删除 API。
- 纯分组子树不显示确认框并执行级联删除。
- 删除后正确刷新树并处理失效选择。
- API 覆盖标签删除、空分组删除、纯分组子树级联删除和含标签子树拒绝删除。

## 非目标

- 不实现节点拖拽。
- 不新增权限控制。
- 不校验分组移动形成的循环结构。
- 不修改右侧标签详情面板。
- 不提交代码，由用户决定 Git 提交时机。
