# 数据集管理列表页设计

## 范围

本次实现数据集管理列表页及通用加载组件。创建数据集、查看归档数据和数据集详情仅保留无行为入口，不实现相应页面或业务操作，也不接入真实后端。

## 通用状态组件

新增 `Loading` 全局组件，薄封装 Ant Design Vue 的 `Spin`，提供国际化默认文案。空状态直接使用 Ant Design Vue 的 `Empty` 组件，不重复封装。状态组件不判断业务状态，不与数据集或表格耦合。

## 页面结构

数据集管理页由页面介绍区、工具区和列表区组成。介绍区包含模块归属、标题、记录数、说明及创建入口；工具区包含搜索框和归档入口；列表区展示数据集名称与说明、版本、项目引用、样本数、状态和详情入口，并提供前端分页。

页面使用现有主布局，不重复实现头部和侧边栏。样式优先复用现有 display、spacing 工具类及 Ant Design Vue 设计令牌。

## 数据与职责

页面通过 `useDatasetStore` 读取列表、加载状态并触发重试。store 继续负责首次加载合并和列表刷新，但移除创建、修改、删除操作；未来实际使用这些操作的界面通过 API 层公开业务函数调用，成功后再通知 store 刷新。

现有 API 缺少版本、项目引用和样本数字段，本期分别展示固定值 `1.0.0`、`0` 和 `0`。这些展示值只存在于页面展示模型，不写回 API 或 store。

## 创建数据集

页面专属 `CreateDataset` 组件同时封装创建按钮与 Modal，内部管理表单、单文件选择和提交状态。名称、类型和文件必填，说明可选；类型仅提供 `3d-point-cloud` 和 `dicom`。Upload 阻止自动上传，本期文件不进入 API 入参。

提交时组件直接调用 `createDatasetApi`，以 `dataset-${Date.now()}` 生成 `code`，并将 `status` 固定为 `enabled`。成功后组件重置并关闭弹窗、展示成功提示并触发 `created`；列表页面收到事件后调用 dataset store 的 `refresh()`。失败时保留弹窗与输入，允许用户重试。

## 状态与异常

- 首次加载：通过 Ant Design Vue `Table` 的 `loading` 属性展示加载状态。
- 空列表或搜索无结果：通过 `Table` 的空状态插槽展示 Ant Design Vue 的 `Empty`。
- 加载失败：展示错误提示和重试操作，避免吞掉异常。
- 正常状态：展示分页后的列表数据。

通用 Table 封装不在本期范围内，当前页面直接使用 Ant Design Vue `Table` 的状态能力。

## 路由与国际化

将现有 `/dataset-management` 动态业务路由的组件由 404 占位页替换为数据集管理页面。路由名称、地址、菜单顺序与元数据保持不变。新增的所有用户可见文案统一维护在简体中文语言包。

## 验证

为通用状态组件、数据集页面的搜索/分页逻辑和路由组件映射提供适度测试，并运行格式检查、ESLint、类型检查、相关测试和生产构建。
