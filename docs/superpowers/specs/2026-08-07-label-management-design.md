# 标签管理界面设计

## 目标

新增 `/label-management` 静态页面，用于呈现标签管理的基础布局骨架。当前阶段只完成视觉结构，不接入业务数据、不实现任何交互，后续可在左右两个独立模块中扩展复杂能力。

## 页面结构

- 页面使用现有 `main` 主布局。
- 页面根容器采用固定最小画布尺寸；视口较小时允许内容被裁切，但不产生页面横向或纵向滚动条。
- 顶部为说明卡片，保留层级与标题区域，正文使用空占位。
- 下方为左右两列卡片：
  - `LabelTreePanel`：标签树静态骨架。
  - `LabelDetailPanel`：标签详情静态骨架。

## 组件边界

### `LabelTreePanel.vue`

负责左侧卡片的视觉呈现，包括标题区、操作按钮位置、搜索框外观和树节点占位。组件不处理搜索、展开、选中、新增或其他事件。

### `LabelDetailPanel.vue`

负责右侧卡片的视觉呈现，包括标题区、工具按钮位置、属性区标题和属性卡片占位。组件不处理编辑、删除、添加属性或数据加载。

### `index.vue`

负责页面级布局编排、固定画布尺寸和两个子组件的排列，不承载具体标签业务逻辑。

## 路由与文案

- 新增唯一命名路由，路径为 `/label-management`。
- 路由使用 `meta.layout: 'main'`，菜单相关元数据遵循现有项目约定。
- 页面可见文案遵循现有国际化方式；当前业务示例文案简化为空或占位，不引入具体标签数据。

## 数据与依赖

- 不新增 API、Pinia store 或外部依赖。
- 使用现有 Ant Design Vue 组件、设计令牌和项目布局工具类。

## 验收标准

1. 访问 `/label-management` 可显示页面。
2. 页面具备顶部说明卡片、左侧标签树卡片和右侧详情卡片三部分布局。
3. 左右复杂模块分别由独立组件承载。
4. 页面不产生滚动条；小视口允许裁切。
5. 所有控件仅为静态展示，不响应交互。
6. 不改变现有页面、公共组件和接口行为。
