# 标签树左侧面板设计

## 目标

完成标签管理页面左侧 `LabelTreePanel` 的树浏览能力，包括真实数据展示、名称搜索、展开收起、标签选择、自动初始选择及加载状态处理。本阶段不实现新增、编辑或删除交互。

## 数据来源

组件直接使用 `useLabelStore()`：

- `tree`：完整且已排序的标签树。
- `mapping`：节点 ID 到 `LabelTreeNode` 的映射。
- `status`：加载状态。
- `initialize()`：等待首次加载或发起重试。

分组和标签已由 store 保证同层分组优先、同类型名称升序，组件不重复排序。

`tree` 由 store 以深度只读形式暴露。组件及 `src/utils/tree.ts` 中不修改源树的方法必须接受 `readonly children`，不得把只读的 `tools`、`props` 或 `children` 断言为可变类型。组件生成展示树时只复制渲染所需字段，不复制未使用的业务数组。

## 树展示

使用 Ant Design Vue `a-tree`，通过 `fieldNames` 将 `id`、`name` 和 `children` 映射为树字段。

- 分组节点显示文件夹图标，仅负责展开或收起，不进入标签选中状态。
- 标签节点显示其 `color` 颜色标记，可以进入选中状态。
- 组件通过 `select` 事件向父页面传递选中的标签 ID。
- 顶部显示标题、标签总数以及两个禁用的新增按钮，为后续 CRUD 预留位置。

## 自动选择

数据首次加载完成后自动选择树中的第一个标签，并触发 `select` 事件。

刷新后：

- 当前标签仍存在时保留选择。
- 当前标签已不存在时选择新的第一个标签。
- 没有标签时清空选择，不触发无效 ID。

## 搜索

搜索仅匹配节点 `name`，忽略关键字首尾空白并按不区分英文大小写处理。

搜索逻辑保留在 `LabelTreePanel.vue` 中，不新增页面工具文件：

1. 局部递归方法判断节点自身或后代是否匹配。
2. 使用 `src/utils/tree.ts` 的 `deepFilter()` 生成新树，不修改 store 数据。
3. 标签匹配时保留标签及祖先分组路径。
4. 分组匹配时保留分组自身，但不保留未独立命中的原始后代。
5. 搜索关键字经过 300ms 节流后再执行递归过滤。
6. 搜索期间自动展开过滤结果中的全部分组。
7. 清空搜索后恢复搜索前的展开状态。

## 状态处理

- 加载中：显示加载状态。
- 加载失败：显示错误说明及重试按钮。
- 无节点数据：显示空状态。
- 搜索无结果：显示搜索空状态。
- 树区域沿用页面固定布局并裁切溢出，不新增页面或面板滚动条。

## 文案与样式

- 用户可见文案统一加入 `src/locales/messages/zh-CN.ts`。
- 根类保留 `label-tree-panel`，内部类使用 `ltp-*` 短前缀。
- 使用现有主题变量、字体类、间距类和 Ant Design Vue 组件。
- 浅色与深色主题下均保持分组、标签、选中态和错误状态可辨识。

## 测试

组件测试覆盖：

- 首次加载后自动选择第一个标签。
- 点击分组仅切换展开状态，不触发标签选择。
- 点击标签触发 `select`。
- 标签搜索保留祖先路径。
- 分组搜索保留完整后代。
- 清空搜索恢复原展开状态。
- 加载、错误、空数据和搜索无结果状态。

## 验收标准

1. 左侧面板展示 store 中的真实标签树数据。
2. 分组可展开收起但不能作为标签选中。
3. 标签选择事件携带正确 ID。
4. 首次加载和刷新后的自动选择符合规则。
5. 搜索结果符合标签祖先路径和分组完整后代规则。
6. 不实现新增、编辑和删除；新增按钮保持禁用。
7. 页面不产生新增滚动条。
8. 相关测试、格式化、ESLint、类型检查和构建通过。
