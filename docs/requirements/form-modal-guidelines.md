# 配置类弹窗统一整改规范

本文件依据 `D:\Document\通用平台\表单类弹窗统一整改规范.md` 整理。开发或修改表单弹窗时必须遵循以下规则。

## 弹窗分级

- 弹窗居中。
- 最大高度 `90vh`，内容内部滚动。
- 最大宽度最好不超过 `50vw`，可按业务设置像 `max(50vw, 800px)` 的最小宽度；屏幕小于业务最小宽度时允许横向滚动。

## 弹窗结构

- 所有弹窗统一采用标准 Header、表单主体和标准 Footer。
- 表单统一采用垂直布局：Label、控件、辅助说明或错误提示。

### Header

- 标题与说明左对齐。
- 标题区域通常包含左侧增删改查通用图标、主标题和说明文字，最右侧为关闭按钮。
- 标题区域底部可使用 `1px` 边框分隔，分割线占满区间。

### Body

- 内边距 `24px`。
- 表单项之间保持 `24px` 间距，包括横向排列的表单项。
- 不为了填充空间增加无业务意义的空白区域。
- 普通分组容器默认不设置外边框、背景和圆角，避免出现“卡片套卡片”。

### Footer

- 顶部使用 `1px` 边框分隔，分割线占满区间。
- 按钮右对齐。
- 按钮顺序统一为“取消”在左、“保存/创建/确认”在右。
- 主操作按钮使用 `type="primary"`。
- 删除、停用等危险操作使用 `danger`。
- 提交时必须显示 Loading，避免重复提交。

## 字体与颜色

- 标题：`18px`，字重 `600`，颜色 `--dm-text`。
- 副标题或说明：`13px`，颜色 `--dm-text-3`。
- 区块标题：`16px`，字重 `600`。
- 字段 Label：`14px`，字重 `500`。
- 正文：`14px`。
- 辅助说明：`12px`。
- Placeholder 颜色不宜过浅，避免低对比度。

## 表单控件

- 统一使用 Ant Design 原生组件。
- 控件统一使用 `size="middle"`，默认高度 `32px`、圆角 `6px`。
- `Textarea` 默认展示一行高度；用户输入换行时，最多自动展开至三行。
- 必填项统一显示必填标识。
- 错误提示显示在字段下方。
- 需要联动的字段必须有明确的禁用逻辑和说明 TODO。
- 普通业务表单一行最多放置 2 个组件。

## 只读页面

- “查看模型”等只读弹窗如果使用看起来可以编辑的输入框，必须设置 `disabled`。
