# 水印组件需求

## 功能目标

提供全局文字水印组件，为尚在建设中的业务页面展示轻量状态标识。

## 使用场景

- 主布局当前路由配置 `meta.developing: true` 时展示水印。
- 普通页面、登录页和其他全屏页面不展示水印。

## 展示与交互

- 组件接收可选 `text` 文本，默认显示“顺昌标注平台”。
- 水印按组件区域重复排列，并围绕文字中心旋转 `-22deg`。
- 水印不拦截鼠标事件，不影响页面内容操作。

## 状态与接口

- 仅支持文字，不使用 Canvas，不提供行列数量配置。
- 不依赖后端接口或第三方依赖。

## 验收标准

- 水印覆盖所属组件区域并重复显示传入文字。
- 主布局建设中页面传入并显示 `developing···`。
- 水印不影响页面点击、滚动和表单交互。
