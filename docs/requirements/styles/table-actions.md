# 表格操作列 UI 规范

## 功能目标

统一管理平台表格中查看、编辑、复制、删除等行级操作的按钮外观、间距和可访问性。

## 使用规则

- 操作列配置必须声明 `className: "table-actions-cell"`，操作按钮外层使用 `table-actions`。
- 行级操作默认使用 Ant Design Vue 普通按钮；删除、移除等高风险操作增加 `danger` 状态。
- 仅显示图标的按钮必须同时提供 `a-tooltip` 和与国际化文案一致的 `aria-label`。
- 操作按钮横向排列、垂直居中，按钮之间固定保持 `8px` 间距；单元格内容不换行。
- 操作列应根据按钮数量设置明确宽度，并在窄屏表格中按需固定到右侧。
- 页面级主要操作放在标题区或工具栏，不在每一行使用主按钮样式。

## 例外

树节点悬浮操作、输入框尾部操作和卡片角标等空间明显受限的场景可以使用文本按钮，但必须在对应需求文档中说明原因，并继续提供 Tooltip、可访问名称、危险态和一致间距。

## 样式依赖

通用样式维护在 `src/styles/ant-design/table.less`，由 `src/styles/ant-design/index.less` 聚合加载。业务页面不得重复定义等价的操作列布局样式。

## 验收标准

- 表格操作按钮使用普通按钮外观，按钮间距为 `8px`。
- 操作单元格不因空间变化自动换行。
- 图标按钮可通过 Tooltip 和辅助技术明确识别含义。
- 危险操作具有统一的危险态视觉反馈。
