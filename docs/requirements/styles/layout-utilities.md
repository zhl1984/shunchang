# 布局工具样式需求

## 功能目标

提供少量、稳定且可组合的全局布局与间距工具类，减少管理页面中重复的基础布局声明。

## 使用场景

- 页面或组件需要快速建立 Flex 容器、方向、换行及常用对齐方式。
- 页面需要使用项目统一的外边距、内边距和元素间距。
- 高频居中或两端对齐场景需要通过单个组合类完成。

## 字段与展示内容

- `display.less`：Flex 容器、伸缩、方向、换行、对齐、尺寸及高频组合类。
- `spacing.less`：基于预设数值生成 margin、padding 和 gap 工具类。
- 间距预设：`0`、`4`、`6`、`8`、`10`、`12`、`16`、`20`、`24`、`32`。

## 交互规则

- 不提供 Flex 默认行为对应的冗余类，例如横向、不换行和起点对齐。
- 高频组合仅保留水平垂直居中和两端居中对齐，不扩展排列组合类。
- 间距类名保持现有 API，生成值使用与数值后缀一致的绝对像素。

## 状态处理

工具类不包含交互状态和主题状态。

## 接口依赖

由 `src/styles/components/index.less` 聚合，并通过全局样式入口加载；无接口依赖。

## 验收标准

- 已使用的布局和间距类保持可用。
- `display.less` 不包含 Flex 默认行为的冗余类，并按职责分组。
- `.pd-24` 输出 `padding: 24px`，`.gap-12` 输出 `gap: 12px`。
- 格式检查、ESLint、TypeScript 检查和生产构建通过。
