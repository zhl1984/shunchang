# 全局主题需求

## 功能目标

基于 Ant Design Vue 的主题能力统一管理平台浅色、深色和跟随系统三种模式，并向业务样式提供可随主题实时变化的设计令牌。

## 使用场景

- 用户切换浅色或深色主题时，Ant Design Vue 组件与平台布局同步更新。
- 用户选择跟随系统时，系统主题变化后页面无需刷新即可同步更新。
- 业务页面需要设置背景、文字、边框或主色时，复用全局主题变量而非硬编码颜色。

## 字段与展示内容

- 主题模式：`light`、`dark`、`system`。
- 实际主题：根据主题模式和系统偏好计算为浅色或深色。
- 品牌主色：使用 Ant Design Vue 默认主色 `#1677ff`。
- 项目颜色变量统一使用 `--dm-*` 前缀，覆盖品牌与交互色、状态色、文字层级、背景层级、边框、填充和控件状态。禁用态统一使用 `--dm-text-disabled`、`--dm-bg-disabled` 和 `--dm-border-disabled`，取值与 Ant Design Vue 浅色、深色主题保持一致。
- 变量名称省略重复的 `color`、`control` 等上下文词；同类颜色层级使用 `2`、`3`、`4` 数字后缀，并通过分组及用途注释保证含义清晰。

## 交互规则

- Ant Design Vue 分别使用 `defaultAlgorithm` 和 `darkAlgorithm` 生成浅色、深色主题。
- `src/styles/theme.css` 使用 `html.theme-light` 和 `html.theme-dark` 分别声明两套 `--dm-*` 变量实值。
- 根节点根据实际主题切换对应类名，并由主题样式同步浏览器原生控件的 `color-scheme`。
- Ant Design Vue 的主题算法与项目 CSS 变量分别负责组件库和业务样式，但必须跟随同一个实际主题切换。
- 主布局菜单跟随当前实际主题，不固定使用深色外观。

## 状态处理

- 用户选择持久化到本地存储。
- 没有已保存设置时默认跟随系统。
- 跟随系统模式下监听系统配色变化并更新实际主题。

## 接口依赖

无后端接口依赖。主题偏好仅保存在浏览器本地。

## 验收标准

- 浅色与深色模式下 Ant Design Vue 组件使用对应主题算法。
- 业务样式可以使用 `--dm-*` 项目颜色变量，并随 Ant Design 实际主题实时更新。
- 浏览器检查 `src/styles/theme.css` 时，可以直接查询浅色和深色主题下所有约定的 `--dm-*` 实值。
- 根节点主题标识与 `color-scheme` 始终匹配实际主题。
- 主布局菜单在浅色模式下使用浅色主题，在深色模式下使用深色主题。
- 格式检查、ESLint、TypeScript 检查和生产构建通过。
