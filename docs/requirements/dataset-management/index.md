# 数据集管理列表页需求

## 功能目标

实现数据集管理模块的列表与创建入口。列表通过 Store 共享完整数据集集合，创建流程按照后端协议完成导入记录创建、浏览器直传和异步导入启动。

## 使用场景

- 用户进入 `/dataset-management` 浏览数据集目录。
- 用户按数据集名称、说明或数据类型搜索当前已加载的数据。
- 用户查看数据集的数据单元数、项目引用数和导入结果状态。
- 用户填写创建表单、选择单个源文件并启动异步导入。

## 字段与展示内容

- 卡片标题：数据集列表。
- 数据集名称：`Dataset.name`，列表第一列展示。
- 数据集类型：`Dataset.dataType`，列表第二列展示。
- 数据集说明：`Dataset.description`，列表第三列展示；未填写时显示 `-`。
- 项目引用：`Dataset.projectReferenceCount`，列表第四列展示。
- 数据单元数：`Dataset.itemCount`。
- 状态：`Dataset.status`，支持 `SUCCESS`、`FAILED` 和空值。
- 创建表单：数据集名称、可选说明、数据类型和单个源文件；导入格式不展示。
- 数据类型和导入格式来自 `GET /dataset-types`，不得在页面硬编码业务选项。

## 交互规则

- 列表使用 Store 提供的完整数据集集合，在前端按名称、说明和数据类型执行不区分大小写的包含匹配。
- 搜索条件变化后回到第一页；列表默认每页 10 条，并在前端分页。
- 加载状态由 Ant Design Vue `Table` 的 `loading` 属性管理，空状态由 `emptyText` 插槽展示。
- 数据集菜单使用现有路径、路由名称和权限键，不再标记为开发中功能。
- 打开创建弹窗时查询可用数据类型和导入格式。
- 选择或切换数据类型时自动使用该类型首个导入格式；无可用格式时禁止提交。
- 文件使用 Ant Design Vue Upload 选择并阻止自动上传，只允许单文件。
- 使用默认导入格式的 `fileExtensions` 校验文件扩展名，匹配时忽略大小写；空扩展名列表不限制格式。
- 有允许扩展名时，上传提示和文件选择器同步显示/限制这些扩展名；为空时不设置前端格式限制，并提示由后端校验。
- 切换数据类型后重新校验已选文件，文件格式不匹配时禁止提交并展示允许的扩展名。
- 提交时先调用创建导入接口，再按 `uploadTarget` 原样直传文件，上传成功后调用启动导入接口。
- 预签名上传使用原生 `fetch`，不得通过项目 Axios 添加平台鉴权或转换响应。
- 启动接口成功即视为创建流程已受理，不等待异步导入完成；随后关闭并重置弹窗、提示成功并刷新 Store。
- 任一步失败均保留表单和文件，解除提交锁并允许重新执行完整流程。
- 创建期间防止重复提交并禁止关闭弹窗。

## 状态处理

- 列表加载中：Table 展示 loading 状态。
- 空列表或搜索无匹配结果：Table 展示 Ant Design Empty。
- 列表加载失败：展示错误信息和重试入口，重试调用 Store `refresh()`。
- 类型选项加载失败：保留弹窗并展示失败反馈，允许重新打开或重试。
- 创建、上传或启动失败：保留弹窗和用户输入，不触发列表刷新。
- 启动成功：提示任务已受理，并刷新完整数据集集合。

## 接口依赖

- `GET /dataset-types`：加载数据类型及其 `formats`。
- `POST /dataset-imports`：提交表单和源文件元数据，获取 `importId` 与 `uploadTarget`。
- `POST /dataset-imports/{importId}/start`：在直传成功后校验源文件并启动异步导入。
- `GET /datasets`：由 Store 通过 API 层获取完整数据集摘要集合。
- API 层从分页项中仅提取 `dataset`；页面不依赖 `importRecord` 或后端分页结构。

## 验收标准

- 列表字段、状态和搜索逻辑使用后端数据集字段，不保留旧 `code`、`type`、`enabled` 兼容逻辑。
- 页面继续使用前端搜索和分页，并展示后端返回的数据单元数与项目引用数。
- 类型和格式选项来自后端且联动正确。
- 文件上传严格使用后端返回的方法、地址和请求头。
- 只有上传成功才调用启动接口，只有启动成功才关闭弹窗并刷新 Store。
- 失败时保留用户输入并允许重试，提交期间不会重复发起流程。
- 用户可见文案均由国际化语言包提供。
- 格式检查、ESLint、类型检查、相关测试和生产构建通过。
