# 动态菜单与路由需求

## 功能目标

为主布局提供按用户会话动态注册的分组菜单。当前阶段只验证导航结构和动态路由机制，不实现具体业务页面或权限模型。

## 使用场景

- 未登录用户访问受保护页面时，不注册业务菜单路由，并跳转至登录页。
- 已登录用户首次进入应用时，前置路由守卫注册全部业务菜单路由。
- 已登录用户使用左侧菜单在各业务入口之间导航。
- 后续用户信息包含权限数据时，可在动态注册入口中按权限筛选路由，无需改造菜单数据来源。

## 路由与数据结构

- 业务路由配置集中维护在 `src/router/index.ts`，并直接向根路由动态注册，不依赖 `home` 路由。
- 每个业务路由显式声明 `meta.layout: "main"`、`meta.menu: true`、国际化标题键、分组键和排序值。
- 路由元数据可保存图标标识；侧栏根据路由配置生成 Ant Design Vue 菜单项。
- 当前所有业务菜单路由复用现有 404 页面组件作为临时内容，不创建业务页面和模拟业务数据。
- 动态注册函数接收当前用户：路由配置了 `meta.permissionKeys` 时按该字段判断，否则按路由 `name` 判断；详情路由可在自身元数据中显式声明所需权限。

## 主布局菜单

- `src/layouts/main/index.vue` 在现有 `a-layout` 和 `a-layout-sider` 架构内直接渲染菜单，不依赖独立侧栏组件。
- 主布局通过 `getGroupedMenus(router.getRoutes(), translate)` 使用已经注册的路由生成菜单，布局内不重复实现权限过滤、分组和排序规则。
- 侧栏展开时使用 `a-menu-item-group` 展示分组标题和组内菜单项。
- 侧栏折叠时将分组菜单扁平化，仅展示可点击的菜单图标，并保留菜单标题提示。
- 菜单图标读取路由 `meta.icon`，当前地址通过 `getActiveMenuPath` 计算选中项。

## 交互规则

1. 前置路由守卫先判断目标路由是否需要认证；公开且非登录路由直接放行，不请求用户信息。
2. 访问 `/login` 时才初始化用户会话；已有用户跳转到第一个有权限的菜单。
3. 未登录用户访问认证路由时，保留目标地址并跳转至 `/login`。
4. 用户存在且业务路由尚未注册时，优先按 `route.meta.permissionKeys` 与 `menuTree.permissionKey` 的交集筛选；未配置时回退按 `route.name` 匹配。
5. 通配路由自身不执行重定向，避免在动态业务路由注册前丢失用户访问的原目标地址。
6. 首次直接访问尚未注册的业务路径时，注册完成后重新解析原目标地址。
7. 动态路由注册并重新解析后仍匹配通配路由时，前置守卫跳转至 `/404` 并通过 `from` 查询参数保留原目标地址。
8. 后续导航不得重复注册同名路由。
9. 主布局侧栏按分组和排序元数据展示菜单，当前路由对应菜单保持选中状态。
10. 主布局折叠时保留图标导航能力；分组标题在无法完整展示时不影响菜单点击。

## 状态处理

- 仅登录页和受保护业务路径初始化期间由路由守卫等待现有用户接口，不额外显示业务加载状态。
- 用户信息获取失败时按未登录处理，不注册业务路由。
- 菜单权限以用户 `menuTree.permissionKey` 与路由显式 `meta.permissionKeys` 或回退 `route.name` 的匹配结果为准，不根据路径推断详情页权限，也不根据 `roleCode` 或 `roleId` 推断菜单。
- 本阶段不在登出时移除已注册路由；受保护路由仍由认证守卫阻止未登录访问。页面刷新会重新建立干净的路由实例。
- 路由注册状态仅保存在当前应用运行时，不写入 Web Storage。

## 接口依赖

- 复用 `getMemberInfoApi` 和 `useUserStore().initialize()` 获取当前用户。
- 不新增接口，复用 `MemberInfo.menuTree` 中的菜单权限字段。
- 后续接入权限时，仅替换动态路由筛选规则，并根据权限变化补充路由移除机制。

## 验收标准

- 未登录状态不注册业务菜单路由，受保护地址跳转至登录页。
- 登录用户仅注册 `meta.permissionKeys` 与 `menuTree.permissionKey` 有交集的业务路由且只注册一次。
- 首次直接访问任一业务路径可以进入主布局，并显示 404 临时内容，而不是跳转至全屏 `/404`。
- 首次直接访问未定义地址时，仅在动态路由处理完成后跳转至 `/404`，并保留原目标地址。
- 侧栏按“工作台、项目生产、配置中心、成员管理”分组，顺序、菜单名称和图标语义与设计稿一致。
- 菜单点击、当前项选中和侧栏折叠行为正常。
- 用户可见菜单文案来自国际化语言包。
- 登录用户访问 `/login` 时替换导航到第一个有权限的业务菜单，且浏览器历史中不保留登录页。
- 用户没有任何可用业务菜单时保留 `/login`，不产生循环重定向。
- 格式检查、ESLint、TypeScript 类型检查和生产构建通过。
