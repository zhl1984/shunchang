# 模型配置页面需求

## 功能目标

还原模型配置页面的基础视觉结构，展示页面说明和 GPU 计算资源的当前任务、等待队列及最近训练记录。

## 使用场景

- 配置人员查看模型配置页面的用途和入口。
- 配置人员了解 GPU 当前任务、排队任务及最近训练结果。
- 配置人员从页面头部进入后续模型接入流程。

## 字段与展示内容

- 页面标题区展示所属模块、页面名称、功能说明和“接入模型”按钮。
- GPU 计算资源区展示当前运行状态、等待队列和最近训练记录。
- 队列条目展示顺序、任务类型和模型名称。
- 训练记录展示结果、模型名称、版本说明、异常说明和发生时间。

## 交互规则

- 本期“接入模型”按钮仅保留视觉入口，不打开未定义的业务流程。
- GPU 区域本期为原型静态展示，不执行任务调度或轮询。
- 模型列表底部使用 Ant Design Vue 分页器，分页总数、每页条数选项和右侧布局与成员管理列表保持一致。

## 状态处理

- 当前无正在运行的具体任务时，仅展示“进行中”状态标题。
- 失败记录使用错误色，成功记录使用成功色。
- 页面需适配浅色、深色主题和常见桌面宽度。

## 接口依赖

模型配置接口统一维护在 `src/api/model-config.ts`，包括模型分页、详情、版本、关联标签 ID 以及模型新增、编辑、删除接口。GPU 任务、等待队列和训练记录接口尚未提供，本期不假设其接口协议。

- 模型列表、新增、编辑和删除均使用模型配置接口，不保留页面模拟模型数据。
- 接入模型弹窗的关联标签树调用 `src/api/label.ts` 中的 `getLabelTreeNodeListApi`，只有 `nodeType` 为 `LABEL` 的节点可被选择并提交其标签 ID。

## 验收标准

- 页面标题区与成员管理页面头部保持一致，GPU 计算资源区的视觉层级、间距和内容与原型一致。
- GPU 计算资源使用独立组件并由页面入口引入。
- 模型列表使用独立组件并由页面入口引入。

## 接入模型弹窗

- 弹窗字段包括模型名称、协议类型、模型用途、API 地址、API 密钥、自迭代配置和模型输出标签。
- 弹窗内容超出视口高度时，主体区域显示纵向滚动条，底部提交和取消操作保持可见；展开关联标签树后仍遵循该滚动限制。
- 自迭代配置并排展示“是否支持自迭代”和“是否开启自迭代”，标题位于按钮上方；支持状态使用禁用按钮，开启状态使用蓝色描边按钮并显示“开启”，关闭状态显示“关闭”。
- 模型名称、协议类型和 API 地址必填；协议类型当前固定为 HTTP JSON。
- 输出标签由标签编码和关联标签组成，可动态新增和删除行。
- 点击关联标签右侧按钮，在当前行下方展开标签树；选择叶子标签后回填并自动收起。
- 表单校验通过后调用新增模型接口；接口成功后关闭弹窗并刷新模型列表，失败时保留当前输入。
- 用户可见文案由国际化语言包管理。
- TypeScript、ESLint 和 Prettier 检查通过。

## 编辑模型弹窗

- 点击模型卡片右上角的编辑按钮打开独立的编辑模型弹窗，并回显当前模型信息。
- 模型名称、协议类型和 API 地址为接入时确定的信息，编辑时只读；模型用途、API 密钥和自迭代开关可修改。
- 已有模型输出标签的编码只读；点击“新增标签”仅添加可编辑的标签编码行。
- 编辑模型时关联标签及其展开按钮均为禁用状态，不允许打开标签树或修改关联关系；内容区滚动和自迭代按钮样式与接入模型弹窗保持一致。
- 保存修改调用模型更新接口；接口成功后关闭弹窗并刷新模型列表，失败时保留弹窗和当前输入。

## 删除模型弹窗

- 点击模型卡片右上角的删除按钮，通过 Ant Design Vue `Modal.confirm` 打开居中的删除确认弹窗，并显示当前模型名称，不单独封装删除弹窗组件。
- 弹窗使用黄色警告图标说明不可逆影响，取消按钮关闭弹窗，删除按钮使用危险操作样式。
- 确认删除后调用模型删除接口，成功后刷新当前分页，失败时保留列表并展示接口错误信息。
