# 树工具需求

## 功能目标

提供与业务无关的树结构转换工具，将平铺数据按调用方指定的 id 和父 id 字段转换为树。

## 使用场景

- 后端返回平铺分类、组织或配置列表时，在前端生成嵌套结构。
- 不同业务使用不同 id、父 id 字段名时复用同一转换方法。
- 需要按后序深度优先顺序处理树节点，并在满足条件时提前终止全部遍历或修改节点数据。
- 需要按相同顺序映射每个节点，并返回不影响原数据的新树。
- 需要按节点条件过滤树，并自动移除没有叶子节点的分支。

## 字段与展示内容

- id 支持字符串或数字。
- 父 id 支持字符串、数字、`null` 或 `undefined`。
- 输出节点保留原始字段，并增加 `children` 数组。
- 深度遍历回调接收当前节点、同级索引、父节点和从 `0` 开始的深度。

## 交互规则

- 不修改输入数组和输入对象。
- 父 id 为空、父节点不存在或形成循环引用的节点作为根节点。
- 保持输入列表中的根节点和同级节点顺序。
- id 重复时抛出错误，避免生成不确定结构。
- 深度遍历采用后序顺序，先处理叶子节点再处理分支节点；只有回调显式返回 `false` 时才中断全部执行。
- `deepEach2`、`deepMap2`、`deepFilter2` 使用前序顺序，先处理分支节点再处理叶子节点。
- 回调接收原始节点引用，可以修改节点字段或当前节点的子节点数组。
- `deepMap` 回调返回映射后的当前节点，输出树会重新组装映射后的 `children`。
- `deepFilter` 回调返回布尔值，分支节点过滤后没有子节点时自动移除。
- 深度遍历固定读取 `children` 作为子节点字段。

## 接口依赖

无外部依赖，由 `src/utils/index.ts` 聚合到全局工具对象。

## 验收标准

- 可通过指定字段名把平铺列表转换为树。
- 输出节点始终包含 `children` 数组。
- 输入数据保持不变。
- 深度遍历完整完成时返回 `true`，被回调中断时返回 `false`。
- 深度映射返回新数组和新节点对象，原树及其节点保持不变。
- 深度过滤返回新数组和新节点对象，原树及其节点保持不变。
- 格式检查、ESLint、TypeScript 检查和生产构建通过。
