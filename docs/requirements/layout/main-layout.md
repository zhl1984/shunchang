# 主布局组件拆分需求

## 功能目标

### Header 布局调整补充

- Header 高度为 56px，与侧栏顶部 Logo 区域垂直居中对齐；内容与侧栏保持 24px 间距。
- 面包屑位于 Header 左侧并保留路由跳转和自定义路径能力。
- Header 右侧按帮助中心、消息中心、用户头像顺序展示；帮助和消息使用 Tooltip 提示文字并暂时禁用。
- 侧栏底部用户信息模块迁移至 Header 用户头像下拉菜单，保留上传任务、个人中心、账号设置和退出登录入口。

在不改变现有界面、菜单和交互行为的前提下，将主布局中的头部和侧边菜单拆分为同目录内部组件，降低 `index.vue` 的职责复杂度。

## 使用场景

- 主布局需要独立维护头部展示结构。
- 主布局需要独立维护侧边菜单、折叠状态和动态路由菜单逻辑。
- 后续调整头部或侧边菜单时，不影响主内容区域的布局编排。

## 组件结构

- `src/layouts/main/header.vue`：负责现有 `a-layout-header`、平台标题和头部样式。
- `src/layouts/main/asider.vue`：负责左侧完整区域，包括 Logo、`a-layout-sider`、主题读取、动态分组菜单、当前菜单选中和菜单跳转。
- `src/layouts/main/index.vue`：负责组合 `header.vue`、`asider.vue`、内容区域和 `RouterView`，并通过根布局 CSS 变量声明 Header 与 Logo 共用高度。
- 主布局内容区域仅在当前路由 `meta.developing: true` 时使用全局 `DmWatermark` 展示默认平台文字水印；其他页面、登录页和全屏页面不显示水印。
- 两个子组件直接放在 `src/layouts/main/`，不创建额外的 `components/` 目录。

## 交互规则

- 左侧 Logo 区展开时显示临时 Logo `SQ` 和国际化平台标题，收起时仅显示 `SQ`。
- 右侧头部继续展示现有国际化平台标题。
- 侧边菜单继续读取已经动态注册的路由，并按现有分组、顺序和图标展示。
- 侧边菜单继续支持展开、折叠、当前菜单高亮和点击跳转。
- Logo 与菜单位于同一个左侧组件中，共用折叠宽度和动画，避免动画不同步。
- Logo 区与右侧 Header 使用父布局继承下来的统一 CSS 高度变量，保证两者严格等高。
- 左侧区域、Logo、菜单和 Header 使用轻量阴影建立区域层次，不使用外边框分隔。
- 主布局内容区在业务页面之前统一显示面包屑，全屏路由不显示。
- 面包屑当前路径项仅展示标题，非当前路径项可以通过对应路由地址导航。
- 主布局通过具名 injection key 提供 `addPath(callback)`，供子页面定制完整路径列表。
- `callback` 接收当前 `route`、`oldPathList` 和 `newPathList`，并返回用于整体替换的完整路径列表；返回空数组时清空面包屑。

## 状态处理

- `index.vue` 在 `.main-layout` 上声明 `--main-header-height: 64px`，不在 JavaScript 中维护布局高度。
- CSS 自定义属性由主布局继承到 `header.vue` 和 `asider.vue`，两个子组件不接收高度 props。
- `asider.vue` 内部维护侧边栏折叠状态、展开宽度 `192px` 和收起宽度 `64px`。
- 主题状态继续读取现有 `useThemeStore`，不新增状态模块。
- 动态菜单继续复用 `getGroupedMenus` 和 `getActiveMenuPath`，不复制路由筛选或排序逻辑。
- Logo 与菜单共同放在 `a-layout-sider` 内，直接复用 Sider 自带宽度过渡，避免重复实现动画。
- Logo 内容显隐使用 `0.2s` 过渡动画。
- 主布局的侧栏宽度、Header 高度和 Logo 高度统一使用像素值，不使用 `rem`。
- 临时 Logo 标记 `SQ` 使用主题主色背景、白色文字和 `6px` 圆角，并保持 `40px × 40px` 尺寸。
- 菜单图标展开时字号为 `18px`，侧栏收起时渐变至 `24px`。
- 图标字号过渡使用 `0.3s cubic-bezier(0.2, 0, 0, 1)`，与 Ant Design Vue Sider/Menu 的慢速动画保持一致。
- 路由变化时保存变化前的完整路径列表，并根据 `route.matched` 生成新的完整默认路径列表。
- 路径标题优先使用动态 `meta.title`；不存在时读取 `meta.titleKey` 对应的国际化文案，没有标题的匹配记录不生成路径项。
- 回调接收的旧、新列表均为快照，调用方不得通过原地修改入参改变布局状态。

## 接口依赖

- 不新增后端接口。
- 不新增第三方依赖。
- 不改变现有路由、语言包、store 或组件公共 API。
- 面包屑不新增后端接口、第三方依赖或全局状态。

## 验收标准

- 主布局视觉、菜单、折叠、主题、选中和导航行为与拆分前一致。
- `index.vue` 仅保留布局组合、共享 CSS 变量和主内容区域职责。
- `header.vue` 和 `asider.vue` 不接收布局尺寸 props；`asider.vue` 自行管理宽度与折叠状态。
- Logo 与 Header 等高，左栏、Logo、菜单和 Header 的阴影显示正常。
- Logo 主色背景和圆角显示正常，菜单图标在侧栏收起过程中平滑放大至 `24px`。
- Header 不再显示平台标题，右侧依次展示主题切换按钮和用户信息下拉模块。
- 主题图标通过本地 IconFont 组件渲染，使用 `currentColor` 适配浅色和深色主题。
- 用户信息左侧展示通用头像，右侧两行展示用户名和角色名称，长文本不得破坏 Header 布局。
- Header 主题按钮只在浅色和深色之间切换；当前为 `system` 时根据实际主题切换为相反的显式模式。
- 点击用户信息区域可打开包含“退出登录”的下拉菜单。
- 退出登录调用 `logoutApi`，成功后清理 user store 并替换跳转 `/login`；失败时保留当前会话和页面。
- 主布局路由变化后面包屑整体更新，并保留变化前的完整路径列表供 `addPath` 回调读取。
- 动态路由标题优先于默认国际化标题，面包屑使用稳定路由地址作为渲染标识。
- 子页面能够通过注入的 `addPath(callback)` 返回完整列表替换当前面包屑。
- 格式检查、ESLint、TypeScript 类型检查、现有测试和生产构建通过。
